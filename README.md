# Polyclinic Frontend

Фронтенд-приложение информационной системы записи пациентов к врачам.

## Технологии

* React 18 — UI-библиотека
* React Router v7 — маршрутизация
* Vite — сборщик проекта
* npm — менеджер пакетов

### Запуск

Запуск в режиме разработки:

```
npm run dev
```

Приложение будет доступно по адресу `http://localhost:3000`.

### Дополнительные команды

* `npm run build` — сборка проекта для продакшена.
* `npm run preview` — предпросмотр продакшен-сборки.

## Использование Docker

Фронтенд запускается автоматически в составе общего стека через `docker compose up -d` из директории бэкенда.

## Структура проекта

* `src/pages/` — страницы приложения: `Landing`, `Patient`, `Doctor`, `Admin`, `Auth`
* `src/components/` — переиспользуемые UI-компоненты
* `src/utils/api.js` — утилиты для работы с API и JWT
* `src/utils/ToastContext.jsx` — контекст уведомлений
